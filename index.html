04

테스트 방법

›

탭해서 여세요. 주소창에 URL을 붙여넣으면 유니버설 링크가 트리거되지 않습니다. 메모·메시지 앱에 링크를 붙여넣고 탭하거나, 위 링크를 직접 탭하세요.

›

루트 배포가 필요합니다. 검증 파일은 항상 도메인 루트(도메인/.well-known/…)에서 읽힙니다. GitHub Pages는 프로젝트 페이지(id.github.io/repo/)가 아니라 사용자 페이지(id.github.io) 저장소로 배포해야 루트에 파일을 둘 수 있습니다.

›

iOS 재설치. AASA는 설치 시점에 캐시됩니다. 파일을 바꿨다면 앱을 삭제 후 재설치하거나 개발 빌드로 다시 배포하세요.

›

Android 검증. adb shell pm get-app-links 패키지명 으로 검증 상태를 확인하고, 필요하면 adb shell pm verify-app-links --re-verify 패키지명 으로 재검증합니다.
